# CANA School — демо веб-портала

Публичное демо платформы управления частной школой: директор, администратор,
преподаватель, ученик, родитель и охрана — каждый со своим интерфейсом.

**Открыть:** https://djumaniyazov.github.io/cana-school-demo/

## Как попробовать

На странице входа есть кнопки быстрого входа для всех шести ролей.
Пароль всех демо-аккаунтов — `Demo123!`:

| Аккаунт | Роль |
|---|---|
| `director@demo.school` | Директор — dashboard, аналитика, рекомендации |
| `admin@demo.school` | Администратор — пользователи, курсы, расписание, финансы |
| `teacher@demo.school` | Преподаватель — журнал посещаемости, оценки, статистика |
| `student@demo.school` | Ученик — расписание, каталог курсов, самозапись |
| `parent@demo.school` | Родитель — дети, оценки, финансы, «Я подъезжаю» |
| `guard@demo.school` | Охрана — очередь выдачи детей |

## Важно

Это **демо-сборка**: данные (ученики, курсы, платежи) сгенерированы и живут
только в вашем браузере. Ваши правки видите только вы, перезагрузка страницы
возвращает исходное состояние. Реального бэкенда и персональных данных здесь нет.

Это статическая сборка портала; исходный код платформы хранится отдельно.
